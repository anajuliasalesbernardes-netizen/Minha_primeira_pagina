# ✨ Página inicial pessoal

Este projeto consiste em uma página inicial moderna, responsiva e visualmente limpa, criada para servir como apresentação pessoal, portfólio digital ou landing page profissional. A ideia principal é oferecer uma interface elegante, organizada e fácil de personalizar, mantendo o código simples e acessível.

## 📁 Estrutura do projeto

- `index.html` — estrutura principal da página
- `estilo.css` — estilos visuais, layout e responsividade
- `script.js` — interações e comportamento dinâmico
- `README.md` — documentação do projeto

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo

Demonstrar habilidades de desenvolvimento front-end com foco em:

- layout moderno
- design limpo e profissional
- boa legibilidade
- responsividade em diferentes dispositivos
- simplicidade na manutenção e personalização

## ▶️ Como executar

### Opção 1: abrir diretamente no navegador
1. Acesse a pasta do projeto.
2. Localize o arquivo `index.html`.
3. Clique duas vezes sobre ele para abrir no navegador.

### Opção 2: usar um servidor local
No terminal, execute:

```bash
python -m http.server 8000
```

Depois, abra no navegador em:

```bash
http://localhost:8000
```
